# Registreringsbevis-generator

Statisk generator för **Registreringsbevis** (Bolagsverket), 2×A4.

Klistra in företagsnamn / org.nr / adress → Generera → PDF.

## Live

https://alshfu.github.io/document/registreringsbevis-generator/

## Format

```
Gotbit AB
559436-6022
Doktor Saléns Gata 5
413 22 GÖTEBORG
```

## Skriv ut

**PDF** öppnar ett rent A4-fönster. Välj A4, 100 %, bakgrundsgrafik.

`index.html`, `ui.css`, `doc.css`, `print.css`, `render.js`, `app.js`
