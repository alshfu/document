# Bankutdrag-generator

Statisk generator för **Nordea / Swedbank / Revolut**-kontoutdrag.

Ange person, välj bank, period, inkomst och utgifter per månad → Generera → PDF.

Bygger på syntesmotorn från `bank/nordea/Kontohandelser.html`.

## Live

https://alshfu.github.io/document/bank-statement-generator/

## Format

```
Anna Andersson
198001011234
Storgatan 1
111 22 Stockholm
```

Sedan: bank, period, inkomst/månad, utgifter/månad.

## Skriv ut

**PDF** öppnar ett rent A4-fönster. Välj A4, 100 %, bakgrundsgrafik.

Märkt **DEMOVERSION · ENDAST FÖR UTBILDNING**.
