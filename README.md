# Документы и шаблоны

Личный архив HTML-шаблонов, переводов и вспомогательных инструментов для работы со шведскими документами: банковские выписки, договоры, доверенности, налоговые формы и прочее.

## Структура

| Путь | Описание |
|------|----------|
| `Transaktion_generator.html` + `Transaktion_generator.js` | Генератор синтетических банковских выписок в стиле Swedbank. Открыть `Transaktion_generator.html`, задать параметры и нажать **Generera**. |
| `Inkomstdeklaration_calculator.html` + `Inkomstdeklaration_calculator.js` | Калькулятор для шведской налоговой декларации (Inkomstdeklaration 1). |
| `table.html` + `table-calc.js` | Редактируемая таблица с автоматическим пересчётом остатка по колонке «Сумма». |
| `transaktion_rus_qa.html` | Пояснения к транзакциям на русском (для запросов банка). |
| `на перевод /RU/` | Переводы документов на русский язык, включая выписку Swedbank. |
| `klart/` | Готовые PDF-документы (зарплатные листы, договоры, декларации). |
| `fullmakt.html`, `fullmakt_2.html` | Шаблоны доверенностей. |
| `bilakuten/` | Документы, связанные с Bilakuten: протоколы, договоры, счета. |
| `advokat_script.html`, `försvarsbrev.html` | Юридические письма и пояснения. |
| `objasnenie_rakhman.html`, `ptd_rakhman.html`, `registreringsbevis_perevod.html` | Разъяснения и переводы по конкретным кейсам. |

## Как пользоваться

1. Открой нужный `.html`-файл в браузере.
2. Если есть кнопки/параметры — меняй их и жми соответствующую кнопку (например, **Generera** или пересчёт в калькуляторе).
3. Для печати в PDF используй **Skriv ut / PDF** или системный диалог печати (`Ctrl+P` / `Cmd+P`).

## Полезные скрипты

- `Transaktion_generator.js` — генерация данных, форматирование сумм в шведском формате (`1 234,56`), работа с рабочими днями и шведскими праздниками.
- `table-calc.js` — делает все таблицы редактируемыми и пересчитывает остаток при изменении суммы.

## Примечание

Генератор выписок создаёт **синтетические тестовые данные** и не должен использоваться как реальная банковская выписка.
